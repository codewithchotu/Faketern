# 🚨 Faketern

AI-powered platform to detect fake internships, scam job posts, and suspicious hiring opportunities.

## ✨ Features

* AI-based scam detection
* Internship trust score analysis
* Fake recruiter identification
* PDF / offer letter analysis
* Modern responsive UI
* Fast verification system

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript
* Vite

## 🚀 Getting Started

```bash
git clone https://github.com/codewithchotu/Faketern.git
cd Faketern
npm install
npm run dev
```

## 🎯 Mission

Helping students stay safe from fake internships and online recruitment scams.
